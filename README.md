# Дополнительные возможности приложения

## Lazy Loading

В приложении реализована **ленивая загрузка компонентов** (Lazy Loading), что позволяет оптимизировать производительность и сократить время первоначальной загрузки. Компоненты загружаются только при необходимости — в момент перехода на соответствующую страницу.

## Error Boundary

Для обработки ошибок в React-компонентах используется **Error Boundary**. Это позволяет перехватывать ошибки рендеринга, жизненного цикла и других JavaScript-ошибок, предотвращая падение всего приложения и отображая резервный UI.

## Infinite Scroll

На страницах **Chapters**, **Episodes** и **Locations** реализован **бесконечный скролл**. При прокрутке страницы вниз автоматически загружаются новые данные, обеспечивая плавный пользовательский опыт без необходимости ручной пагинации.

## Получение данных

Для загрузки данных используется кастомный хук:

```ts
useFetchData(url, pageNumber);
```
