# Структура проекта

## Основной роутинг
- Вся реализация роутинга находится в директории **`app`**, в файле **`./app/routes`**.
- Здесь определяются маршруты перехода между страницами, в том числе для отображения карточек и информации об отдельных элементах.

## Аутентификация
- Страница логина реализована с использованием **контекста** и **Local Storage**.
- Контекст приложения находится в файле **`src/context/LoginProvider.tsx`**.
- Компонент **`LoginProvider`** оборачивает всё приложение в корневом компоненте **`App`**, предоставляя доступ к логин-состоянию всем дочерним компонентам.

## Компоненты приложения
- Основные элементы интерфейса расположены в директории **`./components`**.
- В папке **`./pages`** находятся все страницы приложения, включая авторизацию, отображение карточек и информацию об элементах.

## Навигационные ссылки
- Для реализации ссылок в интерфейсе используются компоненты **`NavLink`**.
- Это позволяет отслеживать, какая вкладка активна в текущий момент, и визуально её выделять.

## Компонент информации об элементе
- Для отображения информации об отдельном элементе используется компонент **`ItemInfo`**.
- Он получает данные из объекта **`state`** при помощи хука **`useLocation`**, что позволяет передавать данные между страницами при навигации.
